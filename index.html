Qui se cache derrière une adresse Web ?

Anatomie d’une adresse Web

Une adresse Web se lit en trois parties. Voici comment décomposer https://devforum.roblox.com/games?lang=fr :

Zoom sur la deuxième partie (le nom complet du site)

roblox.com Domaine principal

Le domaine principal est ce qui nous intéresse.

Comment repérer facilement le domaine principal

  • Repère ://. Commence à lire juste après, par exemple après https://.
  • Trouve le premier /, ? ou # qui suit. Ce qui se trouve avant ce symbole est le nom complet du site. S’il n’y a aucun de ces symboles, pars de la fin.
  • Lis ce nom depuis la droite. Repère l’extension, comme .com ou .net, et prends le nom juste à sa gauche : ensemble, ils forment le domaine principal.

Certaines extensions, comme co.uk, comportent plusieurs parties. Le domaine principal comprend cette extension complète et le nom juste avant. En cas de doute, utilise l’analyseur ci-dessous. Si tu vois @ ou un numéro de port comme :8080, utilise aussi l’analyseur pour isoler correctement le site.

Exemples : le domaine principal est surligné en bleu

https://devforum.roblox.com/
Domaine principal : roblox.com. « devforum » est le sous-domaine.
https://login.roblox.com.verification-urgence.com/connexion
Domaine principal : verification-urgence.com. Le début « login.roblox.com » est un sous-domaine trompeur.
https://accounts.google.com?service=youtube
Domaine principal : google.com. Les options après « ? » ne changent pas le domaine.
https://cadeaux.net/roblox.com
Domaine principal : cadeaux.net. Ici, « roblox.com » est un nom de page trompeur.

À toi de jouer

Colle ou écris une adresse pour repérer son domaine. L’analyse se fait sur cet appareil : aucun site n’est ouvert.

Tu peux aussi saisir une adresse sans « https:// », par exemple www.minecraft.net.
